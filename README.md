# AWS Networking Labs



This repository documents the AWS networking journey.



The goal of this repository is to understand how cloud networks are designed, how traffic flows, and how to troubleshoot connectivity issues.



---



# Topics Covered



## VPC



Virtual Private Cloud concepts:



- VPC creation

- CIDR ranges

- Subnets

- Availability Zones

- Public and private networks



---



## Routing



Topics:



- Route Tables

- Local routes

- Internet Gateway

- NAT Gateway

- Traffic flow



---



## Security



Topics:



- Security Groups

- Network ACLs

- Firewall concepts

- Access control



---

Documentation of how requests travel:



User

↓

↓

## Troubleshooting



Common scenarios:



- Website unavailable

- EC2 cannot reach the internet

- SSH connection failures

- Security Group issues

- Route table problems

- DNS failures



---



# Goal



Continue to build the ability to understand where traffic stops and troubleshoot AWS environments layer by layer.
